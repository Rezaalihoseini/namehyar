# نامه‌یار

برنامهٔ اندروید برای نوشتن نامه‌های اداری فارسی در کمتر از یک دقیقه. کاملاً آفلاین است: نه حساب کاربری می‌خواهد، نه سرور، و اجازهٔ دسترسی به اینترنت هم ندارد.

## نصب

**[دانلود نامه‌یار برای اندروید](https://github.com/Rezaalihoseini/namehyar/raw/main/release/namehyar-0.9.0.apk)** (نسخهٔ ۰٫۹٫۰، حدود ۷ مگابایت)

فایل را روی گوشی اندروید (نسخهٔ ۸ به بالا) باز کنید و نصب کنید. گوشی ممکن است برای نصب از بیرون Google Play اجازه بخواهد.

**[دانلود نسخهٔ آزمایشی اندروید ۰٫۱۰٫۰](https://github.com/Rezaalihoseini/namehyar/raw/refs/tags/v0.10.0-android-preview.1/release/namehyar-0.10.0-debug.apk)** — APK با امضای آزمایشی؛ [توضیحات نصب و تغییرات](release/namehyar-0.10.0-preview.md). پیش از حذف نسخهٔ قبلی، از بایگانی پشتیبان بگیرید.

## چه کارهایی می‌کند

- ساخت نامه با قالب‌های آماده، گیرنده‌های ذخیره‌شده و صفحهٔ A4 زنده
- جابه‌جایی و تغییر ظاهر هر بخش نامه با انگشت
- خروجی PDF و Word با سربرگ، امضا و مهر
- باز کردن فایل‌های Word و PDF و ویرایش آن‌ها
- خواندن نامه‌های اسکن‌شده و عکس نامه، بدون اینترنت
- ابزار کامل جدول: حذف خانه و سطر و ستون، یکی کردن خانه‌ها، شماره‌گذاری ردیف، جمع ستون، مرتب کردن و ساخت جدول از متن یا اکسل
- بایگانی نامه‌ها با جستجو

## نکتهٔ فونت‌ها

فونت‌های B Nazanin، B Titr، B Lotus و B Zar در این مخزن نیستند، چون مجوز انتشارشان روشن نیست. بدون آن‌ها متن فارسی با Vazirmatn نشان داده می‌شود. اگر این فونت‌ها را دارید، می‌توانید از تنظیمات برنامه اضافه‌شان کنید.

## ساخت برنامه از روی کد

به Android Studio نیاز دارید. پروژه را باز کنید یا این دستور را بزنید:

```
gradlew assembleDebug
```

فایل نصبی در `app/build/outputs/apk/debug` ساخته می‌شود.

## ساختار پروژه

- پوستهٔ اندروید با Kotlin: `app/src/main/java`
- موتور صفحه و همهٔ صفحه‌های برنامه با HTML و JavaScript: `app/src/main/assets/web`
- تست‌ها: `tools`

## تست‌ها

راهنمای ارتقای اندروید ۰٫۱۰٫۰، ارزیابی اسکن واقعی و محدودهٔ تست‌ها: [گزارش ارتقا](docs/ANDROID_UPGRADE.md). برای اجرای تمام مجموعه‌های مستقل با سرور محلی خودکار، `npm test` را اجرا کنید (Node.js ۲۲ به بالا، Python 3، curl و Chrome/Chromium).

این تست فقط به Node نیاز دارد:

```
node tools/table-edit-test.js
```

تست‌های `tools/ui-test*.js` به Chrome و یک سرور محلی روی درگاه ۸۷۷۰ نیاز دارند:

```
php -S 127.0.0.1:8770
```

بعضی از آن‌ها اندازه‌ها را با فونت‌های B می‌سنجند و بدون این فونت‌ها ممکن است رد شوند.
